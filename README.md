# C++ 控制台版贪吃蛇游戏
这是一个**多文件模块化**的C++贪吃蛇游戏，适合新手学习工程化开发（头文件+源文件分离、面向对象、Git版本控制）。

## 项目结构

## 运行环境
- VS Code
- MinGW-w64（C++编译器，需配置环境变量）
- Windows 系统（依赖conio.h/windows.h，仅支持Windows）

## 运行步骤
1. 用VS Code打开项目文件夹；
2. 按 Ctrl+Shift+B 编译所有代码（生成snake_game.exe）；
3. 按 F5 运行游戏，按任意键开始；
4. 用 W/A/S/D 控制蛇的方向，按 X 退出游戏。

## 核心功能
- 随机生成食物，吃到食物得分+10且蛇身变长；
- 碰撞检测（边界/自身），碰撞后游戏结束；
- 实时键盘输入响应（无需回车）；
- 显示实时得分。
